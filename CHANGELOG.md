# Changelog

## 0.1.0.0 - 2026-06-04

### Added

- Initial Russian-first Road To IOI website scaffold with Next.js, TypeScript, App Router routes, and static generation.
- Russian landing page, guided start page, curriculum, module pages, glossary, teacher page, Kazakhstan olympiad map, and attribution/license page.
- Source-linked content model with 6 starter modules and 30 competitive programming glossary terms.
- Local-only module progress tracking with graceful fallback when browser storage is unavailable.
- Content validation and route smoke QA scripts for source metadata, glossary links, internal routes, semantic landmarks, and 404 behavior.
